# Bento Orders

Мобильная браузерная головоломка о кухне. Четыре ленты движутся сами. Нажимайте на видимые блюда, чтобы собрать заказы из трёх одинаковых предметов. Лишняя еда попадает на полку с пятью местами. Когда заказ сменяется, подходящие блюда с полки автоматически отправляются в него.

В игре семь уровней на 12, 80, 140, 220, 320, 450 и 600 заказов. Победа открывает следующий уровень. Обучение можно пропустить.

## Блюда со скриншотов

Для 35 различимых видов еды подготовлены оригинальные изображения. Названия некоторых блюд условные, поскольку на скриншотах нет подписей.

- Роллы и рис: маки с лососем, кимбап с разноцветной начинкой, прямоугольные мусуби, нигири тамаго, онигири с тёмным нори, онигири с зелёным нори, инари с кунжутом.
- Шпажки и горячее: корндог с соусом, сосиски с золотистыми кусочками, шашлычок с зелёным перцем, глянцевые данго в глазури, закрученная жёлтая шпажка, хрустящий кусочек с красным соусом, рисовые палочки в красном соусе, красные капустные свёртки, паровые булочки, слоёные полоски.
- Сладости: разноцветные данго, мини-оладьи с посыпкой, дораяки, зелёные пирожные с прослойкой, зелёный рулет, матча-квадратики, розовые цветочные сладости, сакура-моти с листом, клубничные моти, фиолетовые лепёшки, тайяки, тосты с шоколадом, двухцветное мороженое, парфе с матча, трёхцветные булочки и оранжевые чашечки с начинкой.
- Напитки: светлая бутылочка с зелёной крышкой и молочный напиток с красной крышкой.

Интерфейс использует светлую палитру и при включённой тёмной теме устройства.

## Запуск

Нужен Node.js 22.18 или новее.

```sh
npm install
npm run dev
```

Откройте адрес, который выведет Vite. На телефоне используйте тапы, на компьютере — мышь. После фокусировки поля клавишей Tab стрелки выбирают видимое блюдо, а Enter или пробел подтверждают выбор. Escape ставит игру на паузу.

## Сборка и проверки

```sh
npm test
npm run build
npm run preview
```

`npm run build` проверяет TypeScript и создаёт статическую сборку в `dist/`. Для публикации достаточно разместить содержимое каталога на статическом хостинге. Шрифты и 35 изображений блюд в WebP включены в сборку. Лицензии шрифтов находятся в `dist/licenses/`.

`npm test` проверяет заказы, слои, хранение, переносы, поражение, баланс еды и попадание по движущимся предметам. Для каждого уровня тест воспроизводит решение, дожидаясь видимости каждого нужного предмета.

## Исходники

- `src/game.ts` — правила и игровой цикл на уровне данных.
- `src/levels.ts` — фиксированные уровни и решения.
- `src/geometry.ts`, `src/scene.ts` — координаты, ввод, анимации и отрисовка поля в Canvas 2D.
- `src/main.ts` — меню, подсказки, пауза и экраны результата.
- `src/audio.ts`, `src/preferences.ts` — звуковые эффекты и сохранение настроек.
- `assets/food/` — иллюстрации блюд.
